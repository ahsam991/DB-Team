1 · Project Overview & Visualization

🌐 What Is Gamified Recruitment?

Gamified Recruitment is a platform that transforms the traditional hiring pipeline into an interactive, game-like experience. Instead of boring forms and static tests, candidates progress through structured interview programs composed of multiple rounds, each containing questions that may include scenarios, dialogues, timed challenges, and weighted scoring.

🧠 High-Level Business Logic

business_logic.flow
🏢 Company
  └──► 📋 Creates Interview Program(s)
         └──► 🔄 Defines Rounds (ordered stages)
                └──► ❓ Assigns Questions to Rounds
                       ├──► 🎭 Dialogue-based (with dialogue_lines)
                       ├──► ✅ MCQ-based (with options & weightage)
                       └──► 📝 Open-ended / Other types

👤 Candidate
  ├──► 📝 Registers & Enrolls in Program(s)
  ├──► 🔗 (or) Receives One-Click Token for quick access
  ├──► 🎮 Enters Round → Answers Questions
  ├──► 📊 Answers are scored (auto or weighted)
  └──► 🛡️ Anti-cheat monitors IP, screen & webcam recordings

2.8 · Phase 7

🛡️ Anti-Cheat Real-Time Monitoring

👥 Owner: Us

A. 🖱️ Tab / Window Switch Detection

System tracks tab-switch and window-blur events.

Violation #Action
1st & 2nd⚠️ Warning displayed
3rd🔒 Exam auto-submitted immediately

Auto-Submit Outcome: current answers locked; session tagged auto-submitted — tab violation; recording saved.

B. 🖥️ Full-Screen Exit Detection

System detects when candidate exits full-screen. Same 3-warning rule applies.

Violation #Action
1st & 2nd⚠️ Warning; must re-enter full-screen
3rd🔒 Exam auto-submitted

C. 📹 Camera / Mic Drop Detection

📉

Feed drops

Webcam feed drops or microphone is revoked.

🚩

Session flagged

System flags the session automatically.

🔁

Re-grant & resume

Candidate is prompted to re-grant permissions. Exam does not auto-submit — the session pauses functionally and resumes when access is restored.

D. 🔒 Question Navigation Lock

✋ No back navigation allowed ➡️ "Next" moves forward only ❌ Cannot skip and return

E. 📊 Continuous Recording

Screen & webcam recording runs the entire duration. All events are timestamped and synced with recordings, enabling cross-verification during audit.

Question displayed Answer submitted Warning issued Violation triggered

4.1🏢

companies

📖 The root organization entity. Each company is a hiring organization that creates programs, questions, and manages candidates. This is the top of the hierarchy.

🔄 How It Works

A company registers on the platform, and all their content (programs, questions, candidates) is scoped under their company_id. Multi-tenancy is achieved through this FK relationship.

interviewprograms

📖 A hiring workflow created by a company. Each program is a complete hiring initiative with multiple rounds, a candidate pool, and pass/fail criteria.

🔄 How It Works

A company creates a program for a specific role/department. The program has a start date, end date, and status (active, archived, planning). Candidates enroll in programs via candidateprograms. Rounds within the program are ordered and executed in sequence.

4.3🔄

rounds

📖 An ordered stage within a program. A program has multiple rounds (e.g., Aptitude → Technical → HR), and rounds contain the actual questions candidates answer.

🔄 How It Works

Each program contains ordered rounds. round_order determines sequence. Each round has a start/end date defining when it's available. Candidates progress through rounds, answering questions and being monitored for integrity. extra_time_minutes supports accommodations.

🟢 Sequencinground_order enforces strict progression
🟡 Timingstart_date and end_date define exam window

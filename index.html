04 · Golden Rules

Always Follow

AI ecosystem-এর প্রতিটি ব্যবহারে এই নিয়মগুলো চিরকাল প্রযোজ্য।

✓
AI is an assistant, not the final decision maker
সিদ্ধান্তের মালিক সর্বদা টিম মেম্বার।
✓
Every SQL query must be tested before production
Production-এ deploy-এর আগে বাধ্যতামূলক validation।
✓
Cross-check critical outputs with multiple AI tools
Multiple model verification → higher confidence।
✕
Never share secrets
Database Passwords, API Keys, Production Credentials, Sensitive Client Data।
✓
Business logic validated by responsible member
Responsible person-এর sign-off অপরিহার্য।
✓
AI documentation reviewed before sharing
Publish-এর আগে human review বাধ্যতামূলক।
